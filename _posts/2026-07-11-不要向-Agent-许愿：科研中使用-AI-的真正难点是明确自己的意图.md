## 1. 我遇到的问题：Agent 越强，自己的思路反而越混乱

在使用 Agent 做科研时，我发现自己一直存在一个问题：我写下了 Prompt，但我自己并不知道这个 Prompt 真正的意图是什么。

很多时候，我只是想到什么就写什么，脑子里只有一个模糊的方向，就立即开始让 Agent 工作……

## 2. 一个明显的现象：我开始忘记自己为什么要做这件事

我平时会同时开多个 Agent。它们都有环境执行能力，不只是聊天窗口……

这种状态带来了一个明显的现象：过一段时间之后，我甚至记不住，当初为什么要让 Agent 做这个任务……

## 3. 真正的问题不在 Agent，而在 Prompt 之前

后来我意识到，问题并不在 Prompt 本身，而是在 Prompt 之前。

写 Prompt 之前，我应该先思考：

- 我目前已经做了什么？
- 接下来真正需要解决的问题是什么？
- Agent 已经完成了什么？
- 我观察到了哪些结果？

这些应该先由我自己明确，而不是边想边让 Agent 执行。

## 4. 从“许愿”到“收集信息”

我过去更像是在向 Agent 许愿：

“我希望你帮我实现这个目标。”

但科研过程并不是一次性得到正确答案。

实验成功、失败、代码报错，本质上都是信息反馈，都在帮助我更新对问题的理解。

## 5. Agent 的位置：执行者，而不是研究者

使用 Agent 后，人类真正需要承担的工作没有消失。

明确问题、判断方向、设计实验、解释结果，这些仍然是研究者自己的职责。

Prompt 不应该只是一个任务描述，而应该是自己思考之后形成的明确意图。

Agent 可以加速执行，但不能替代研究中的判断。
